# Personal Portfolio Website

## Project Description

A professional and responsive personal portfolio website created as part of my CodeOrbitTech internship task.

This website showcases my profile, skills, projects, resume, and contact information.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive design
- Professional and modern UI
- About Me section
- Skills section
- Projects section
- Resume section
- GitHub and LinkedIn links
- Contact section
- Mobile-friendly layout

## Setup Instructions

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
4. The portfolio website will run in the browser.
